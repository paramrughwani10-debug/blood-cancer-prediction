# Blood Cancer Prediction Website

## Run on your laptop (Windows)
1. Install Python 3.10+ from python.org (tick "Add Python to PATH").
2. Open Command Prompt in this folder and run:
   pip install -r requirements.txt
   streamlit run app.py
3. The site opens at http://localhost:8501

## Deploy free (Streamlit Community Cloud)
1. Upload this whole folder to a GitHub repository (keep the `data` folder).
2. Go to share.streamlit.io, sign in with GitHub, click "New app".
3. Pick your repository, set the main file to `app.py`, click Deploy.
4. You get a public link to put in your project file.
